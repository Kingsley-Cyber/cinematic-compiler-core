# ADR-O69 — A bootstrap directory for resuming after a compaction

<!-- docs-version: 1.0 -->

## Status
accepted

## Date
2026-10-11

## Decided By
owner

## Scope
docs

## Decision
`docs/bootstrap/` is the agent's own starting point after a context compaction or in a new session: a README with
the resume steps, a generated state.md (where the work stands), the environment, the working agreements with the
owner and the lessons already learned. AGENTS.md and CLAUDE.md reference it in addition to their own content;
`/bootstrap` opens it in Claude Code.

## Context
Owner request of 2026-10-11 ("create a bootstrap for yourself to reference, update AGENTS.md or CLAUDE.md to reference
a bootstrap dir for all future reference in addition to its current md"), before a compaction.

## Consequences
- state.md is generated by kernel/docs_plane.py and checked for staleness by the gate; the README is frozen.
- The agent appends to lessons.md after a slice that teaches something.

## Alternatives Considered
- Keeping the resume steps only in AGENTS.md: rejected by the owner's request for a directory.
